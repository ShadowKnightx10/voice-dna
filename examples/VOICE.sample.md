## 4. Anti-Slop Safeguards

1. **The Coffee Table Test**: If a line sounds like it belongs on a corporate marketing billboard, delete it immediately.
2. **The Metric Grounding Rule**: Every verb describing an improvement must be tethered to a real production delta (ms, MB/s, dollar savings, CPU cores freed).
3. **Active Personal Ownership**: Always state who did what. *"I rewrote the query generator"*, never *"The query generator was optimized"*.
